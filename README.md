# 밑바닥 인생 (BottomLife)

Android native offline idle clicker. Tap to earn, hire workers, own businesses, mine deeper, upgrade drills, collect gems, and prestige for permanent bonuses.

## APK
GitHub Actions → Build Android APK → latest successful run → Artifacts → BottomLife-debug-apk. Extract ZIP and install `app-debug.apk`.

## Rules
- Money and business reset on rebirth, but soul points, permanent upgrades, gems, mining depth and achievements remain.
- Automatic earnings continue offline for up to 8 hours.
- Save data is local to the device. Uninstalling may delete it.
